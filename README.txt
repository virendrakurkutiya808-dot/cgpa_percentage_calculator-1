CGPA + Percentage Calculator
Python + Flask + HTML + CSS

Run:
1. Open terminal in this folder.
2. pip install -r requirements.txt
3. python app.py
4. Open: http://127.0.0.1:5000/

IMPORTANT:
The grade-point scale and CGPA-to-percentage formula can differ by university.
This demo uses:
90+=10, 80-89=9, 70-79=8, 60-69=7, 50-59=6, 40-49=5, below 40=0.
Percentage = CGPA x 10.
Change these rules in app.py if your college/university uses a different formula.
